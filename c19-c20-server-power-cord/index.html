C19 C20 server power cord

Required cable for a C20 inlet: IEC C19–C20 jumper. C19 into the server. C20 into the PDU C19 outlet.

When you need this cord

Use it when the PSU nameplate is 16 A class or the inlet is physically C20. A Dell R760 with a 2400 W PSU is in this group. NVIDIA DGX H100/H200, B200 and B300 AC systems ship locking C19/C20 cords: 250 VAC, 20 A, 1200 mm.

Do not substitute C13–C14. The inlet will not accept C13, and the current class is wrong.
