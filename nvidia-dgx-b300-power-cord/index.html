NVIDIA DGX B300 power cord

By the RackMatch team · Updated 2026-11-10 · Sources linked on the page

On the AC/PDU version NVIDIA specifies the same cord family: C19/C20, 250 VAC, 20 A, 1200 mm (UL62 / IEC 60227 cord, IEC 60320-1 connectors).

The B300 AC chassis has 12 power inlets (12 × 3.2 kW PSUs). Each PSU needs its own cord. NVIDIA also sells a DC busbar version: no C19/C20 jumper, 54 VDC busbar instead.

Maximum current per AC outlet in the B300 intro table is 16 A per PSU at 200–240 VAC. The cord is still specified 20 A.

Source

NVIDIA DGX B300 User Guide: power cord table and AC vs busbar

Do not assume the busbar SKU needs IEC jumpers. It does not.

Frequently asked questions

What power cord does the NVIDIA DGX B300 need?

AC versions use 16/20 A class C19/C20 cords at 200–240 V. Check the exact cord set and count in the NVIDIA user guide listed on this page. Some models also ship in a DC busbar version that needs no AC cords.

Can a DGX run on 120 V?

Plan for 200–240 V. The power supplies are rated for high-line input, and 120 V circuits cannot deliver the load per cord that these systems need.

What PDU outlets does a DGX need?

C19 outlets, enough of them for every PSU, split across two PDUs on separate circuits for redundancy. C13 outlets cannot feed these PSUs.

How much power does a DGX rack need?

Several kilowatts per system. Use the maximum system power from the NVIDIA spec, add margin, and check it against the PDU and circuit with the PDU calculator.
