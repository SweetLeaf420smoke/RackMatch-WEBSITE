Dell PowerEdge R760 + APC AP8941 Power Cable

Compatible for the 2400 W PSU. Required cable: IEC C19–C20.

ConnectorC19 into the R760 C20 inlet; C20 into an AP8941 C19 outlet
Voltage / currentServer PSU 200–240 V / 16 A. PDU 230 V, 32 A input
LockingC19 outlets; use a locking C19/C20 jumper if specified

Why this cable

The AP8941 is C19-only. A 2400 W R760 PSU has a C20 inlet, so the jumper is C19–C20. A C13–C14 cord does not fit this inlet. Lower-watt R760 PSUs can be C14; check the PSU nameplate.

Sources

Server: Dell PowerEdge R760 power supply units

PDU: Schneider Electric APC AP8941

Check the live nameplate and the vendor PDF before you order cable. High-watt PSUs on the same chassis can change the inlet.
