Dell PowerEdge R650 + Eaton EMA333-10 Power Cable

Compatible. Required cable: IEC C13–C14.

ConnectorC13 into the R650 C14 inlet; C14 into an EMA333-10 C13 outlet
Voltage / currentServer PSU 100–240 V / 10 A. PDU 230 V, 16 A input
LockingStandard C13; locking sleeve optional

Why this cable

Both ends are the 10 A IEC pair: R650 C14 inlet and Eaton C13 outlets. The PDU input is 16 A; the jumper to this server is still C13–C14. There is no C19 on this PDU, so a C19–C20 cord does not apply.

Sources

Server: Dell PowerEdge R650 owner’s manual (PDF)

PDU: Eaton metered-input rack PDU
