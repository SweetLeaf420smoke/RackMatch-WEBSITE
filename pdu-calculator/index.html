How it works

Usable power = volts × amps (× 1.732 for three-phase), × 0.8 if you load to 80% of the breaker. With A/B feeds each PDU must be able to carry the whole rack alone, so the power limit is counted against one PDU. Full explanation and a worked example: how many servers per PDU.

Frequently asked questions

How is usable PDU power calculated?

Volts × amps for single-phase, volts × amps × 1.732 for three-phase, then × 0.8 if you apply the North American continuous-load rule.

Why does the calculator ask for A/B feeds?

With redundant feeds each PDU must carry the whole load alone, so the server count is limited by one PDU.

Is the result enough to order hardware?

It is an estimate. Check breaker ratings, local code and the vendor power calculator for your exact configuration.
