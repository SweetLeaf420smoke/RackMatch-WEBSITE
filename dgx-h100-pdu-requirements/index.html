DGX H100 PDU requirements

By the RackMatch team · Updated 2026-11-10 · Sources linked on the page

The cord NVIDIA ships is C19/C20. The PDU must present C19 outlets (or a locking C19 equivalent that accepts that coupler). A C13-only PDU does not feed this system. See C13 PDU, C19 server.

Count: six locking cords in the H100/H200 kit, so six C19 drops if you populate every PSU cord NVIDIA packed. Electrical rating on the cord table: 250 VAC, 20 A, 1200 mm.

Facility power (whips, phases, redundant feeds) is in the NVIDIA site-planning sections of the same user guide. This page covers only the IEC jumper and outlet shape.

Related: DGX H100 power cord.

Source

NVIDIA DGX H100/H200 User Guide

Plan C19 capacity before the chassis lands. C13 strips will not work.

Frequently asked questions

What PDU does a DGX H100 need?

PDUs with enough C19 outlets for all PSUs at 200–240 V, split across two feeds, with capacity for the full system power on each side.

How many power cords does a DGX H100 use?

The ship kit lists six C19/C20 class cords. Check the NVIDIA user guide for your exact configuration.

Can I use C13 outlets for a DGX H100?

No. The PSUs need C19 class connections.
