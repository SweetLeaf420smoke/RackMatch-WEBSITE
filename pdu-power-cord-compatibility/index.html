PDU power cord compatibility

The PDU does not “take any IEC cord”. It takes the outlet shape printed on the strip.

PDU C13 outletAccepts C14. Pair with a C14 inlet using C13–C14
PDU C19 outletAccepts C20. Pair with a C20 inlet using C19–C20
Mixed PDU (C13 + C19)Pick the outlet that matches the PSU, not the nearest empty hole

Locking

Some PDUs (APC locking C13, Raritan SecureLock, NVIDIA ship-kit lock on C19/C20) need a matching coupler. A standard jumper will seat but will not lock.
