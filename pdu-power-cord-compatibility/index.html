PDU power cord compatibility

By the RackMatch team · Updated 2026-11-10 · Sources linked on the page

The PDU does not “take any IEC cord”. It takes the outlet shape printed on the strip.

PDU C13 outletAccepts C14. Pair with a C14 inlet using C13–C14
PDU C19 outletAccepts C20. Pair with a C20 inlet using C19–C20
Mixed PDU (C13 + C19)Pick the outlet that matches the PSU, not the nearest empty hole

Locking

Some PDUs (APC locking C13, Raritan SecureLock, NVIDIA ship-kit lock on C19/C20) need a matching coupler. A standard jumper will seat but will not lock.

Related: C13 PDU, C19 server, server to PDU power cord.

Catalog examples on the home page: APC AP8853 (C13+C19), APC AP8941 (21 C13 + 3 C19), Eaton EMA333-10 (21 C13 + 6 C19 + 1 5-20R), Raritan PX3-5496V (24 C13).

Frequently asked questions

How do I match a PDU and a server?

Compare the PDU outlet type (C13 or C19) with the server PSU inlet (C14 or C20) and pick the jumper that joins them.

What if the PDU has only C13 outlets and the server has C20 inlets?

There is no safe standard cord. Use a PDU with C19 outlets.

Do PDU input plugs matter?

Yes. The PDU input (NEMA L6-30, IEC 60309 and others) must match the circuit and socket at the site.
