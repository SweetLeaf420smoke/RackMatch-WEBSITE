Dell PowerEdge R760 + APC AP8853 Power Cable

Compatible for the 2400 W PSU. Required cable: IEC C19–C20.

ConnectorC19 into the R760 C20 inlet; C20 into an AP8853 C19 outlet
Voltage / currentServer PSU 200–240 V / 16 A. PDU 230 V, 32 A input
LockingOptional locking C13 (AP870x / similar); this pair uses C19

Why this cable

A R760 PSU in this catalog uses a C20 inlet. APC lists AP8853 as 36 × C13 and 6 × C19. Use a C19 outlet and a C19–C20 jumper. A C13–C14 cord does not fit this inlet. Lower-watt R760 PSUs can be C14 and then use a C13 outlet instead.

Sources

Server: Dell PowerEdge R760 PSU specifications

PDU: Schneider Electric APC AP8853

Check the live nameplate and the vendor PDF before you order cable. High-watt PSUs on the same chassis can change the inlet.
